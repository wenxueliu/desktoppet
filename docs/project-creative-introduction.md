# Desktop Pet 项目创作介绍

Desktop Pet 是一个面向创作者的跨平台桌面宠物客户端。它不是把一张会动的图片简单贴在桌面上，而是把素材包、动画剪辑、触发规则和本地运行时组合成一套可编排的互动系统，让桌面上的小伙伴能够根据点击、拖拽、鼠标方向、计时器、番茄钟和应用生命周期做出不同回应。

项目的核心创作思路是把“桌宠”从固定脚本变成可分享的作品格式。创作者可以用 `.petpack` 打包角色素材、动画和规则；用户可以在控制面板里导入、调整、导出，并让修改实时生效。默认动画、一次性动画、循环动画和关键帧动画共同构成角色的动作语言，规则引擎则负责把用户行为转译成表情、移动、消息和状态变化。

在技术实现上，Desktop Pet 采用 Electron 三进程架构：主进程负责窗口、IPC、托盘、文件与系统能力；preload 通过受控 API 维持安全边界；renderer 分别承载宠物窗口和模块化控制面板。项目重视本地优先、安全导入、原子写入和双语体验，希望让桌宠既有轻松好玩的亲近感，也具备长期创作和扩展所需的工程稳定性。

一句话概括：Desktop Pet 让桌面宠物拥有自己的动作、规则与性格，也让每个创作者都能把一套互动想法打包成可以运行、可以分享的桌面作品。
